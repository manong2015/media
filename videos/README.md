# 视频工程

本目录存放实际制作工程，原则上一条视频对应一个独立子目录。

新工程推荐结构：

```text
videos/YYYY-MM-DD-topic-slug/
├─ AGENTS.md       框架或工程专用约束（需要时）
├─ BRIEF.md        目标、受众、时长、画幅和交付要求
├─ SCRIPT.md       最终脚本或指向 content/scripts 的说明
├─ assets/         仅供该视频使用的素材
├─ compositions/   画面与动画源文件（按所用工具调整）
├─ renders/        母版、平台版与质检输出
└─ publish/        与该视频强相关的平台发布包（可选）
```

已有工程保持当前结构，不为套用模板而强制迁移。
