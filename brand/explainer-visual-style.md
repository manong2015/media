# 科普讲解视觉样式规范（v1）

- 适用：AI 概念科普、原理讲解、产品对比类视频。
- 来源：参考 B 站「小白debug」的扁平信息图风格（2026-10-25 观察），已按牛同学品牌色和竖屏 9:16 改造。
- 原则：**学习样式语言，不复制其素材**。不用其水印、doge 表情、AI 卡通角色、具体图示或截图。

## 一、风格一句话

浅灰白干净底 + 深蓝粗体大字章节卡 + 圆角色块搭建的架构图 + 牛同学担任情绪角色。
信息全部由图形和大字承载，不露脸，画面始终只讲一件事。

## 二、色板（Design Tokens）

| Token | 色值 | 用途 |
|---|---|---|
| `--bg` | `#EEF1F5` | 全局背景，冷调浅灰白 |
| `--bg-grid` | `#DDE3EB` | 背景网格线、透视地面（可选） |
| `--surface` | `#FFFFFF` | 卡片、窗口、色块内底 |
| `--ink` | `#0B1B3F` | 主文字、章节卡大字（取自牛同学深蓝装甲） |
| `--primary` | `#1F4FA8` | 主色块、外层容器 |
| `--primary-soft` | `#CFDDF3` | 主色块浅底、内层容器 |
| `--accent` | `#1677E6` | 关键词高亮、连线、当前焦点（取自装甲发光蓝，加深一档以保证浅底对比度 ≥ 3:1） |
| `--accent-glow` | `#5CD3F5` | 光效、流动线、选中描边 |
| `--muted` | `#6B7A99` | 次要文字、注释、未激活元素 |
| `--alert` | `#FF7A2F` | **仅限**牛同学形象本身及极少量警示点，不作关键词色、不做大面积色块 |

搭配规则：

1. 一屏最多 **1 个主色 + 1 个强调色**；层级靠「深蓝 → 主蓝 → 浅蓝」明度区分，不靠增加色相。
2. 对比两样东西时用 `--primary` vs `--muted`（主角 vs 配角），不要用红绿对立。
3. 代码/命令关键词：命令主体用 `--ink`，参数/动作用 `--accent`。

## 三、字体

| 角色 | 字体 | 字重 |
|---|---|---|
| 章节卡、标题 | Noto Sans SC（思源黑体同源） | Black 900 |
| 图示标签、字幕 | Noto Sans SC | Bold 700 |
| 代码、命令、英文术语 | JetBrains Mono | Bold |

- 两款均为 SIL OFL 授权，可商用，已入库：`assets/fonts/NotoSansSC-VF.ttf`、`assets/fonts/JetBrainsMono-VF.ttf`（许可证同目录）。
- 中英混排时英文不单独换字体（代码除外），保证一行内字重一致。

## 四、画布与安全区（1080 × 1920）

```text
y=0    ┌──────────────────────────┐
       │  平台顶部 UI（避让）      │
y=160  │                [@牛同学不上班] ← 账号标识，右上，36px，--muted
y=220  ├──────────────────────────┤
       │                          │
       │      主信息区             │  ← 章节卡 / 架构图 / 对比图
       │      x: 72 – 936          │     （右侧留 144px 给点赞栏）
       │                          │
y=1300 ├──────────────────────────┤
       │      字幕区 y≈1340–1480   │
y=1520 ├──────────────────────────┤
       │  平台底部 UI（避让）      │
y=1920 └──────────────────────────┘
```

- 左右边距 72px，右侧额外避让到 x≤936。
- 牛同学出场位置：主信息区左下或底部居中，高度 ≤ 画面 35%，不压字幕。

## 五、核心组件

### 1. 章节卡（Chapter Card）

- 整屏 `--bg`，居中一行大字，例如「MCP 是什么」。
- 字号 120–140px，`--ink`，Heavy；超过 8 个字时拆两行，行高 1.2。
- 可选：大字下方 `--accent` 短横线 120×10px，圆角。
- 时长 1.2–1.8s；每个小问题开始前出现一次。

### 2. 架构色块（Block）

- 圆角矩形，圆角 24px（内层 16px）。
- 外层容器：`--primary` 底 + 白字，或 `--surface` 底 + 4px `--primary` 描边。
- 内层组件：`--primary-soft` 底 + `--ink` 字。
- 标签 44–56px Bold，图标在上、文字在下，内边距 ≥ 32px。
- **竖屏改造**：嵌套关系从上往下叠（上层 → 下层），不左右并排超过 2 列。

### 3. 连线与数据流

- 4–6px `--accent` 线，端点圆头；流动用 `--accent-glow` 光点沿线移动。
- 虚线（8px 间隔）表示「可选/远程」，实线表示「直接调用」。

### 4. 关键词打字

- JetBrains Mono，72–88px，逐字打出（每字 40–60ms），末尾闪烁竖线光标 `--accent`。
- 一屏最多 2 行。

### 5. 字幕

- 单行居中，≤ 16 字；52–58px Bold 白字。
- 底板：`rgba(11,27,63,0.78)`（`--ink` 78%），圆角 12px，左右内边距 24px。
- 当前关键词可变 `--accent-glow` 色，单句最多 1 处。

### 6. 录屏窗口（产品实测用）

- 录屏放进 `--surface` 圆角窗口（圆角 28px，阴影 `0 20px 60px rgba(11,27,63,0.18)`），顶部 macOS 三点。
- 重点用 `--accent` 下划线（6px）或圆角框圈出，不用红色。
- 竖屏下窗口宽 936px，必要时局部放大（punch-in 1.3–1.6×）。

### 7. 牛同学情绪位

- 替代对方的 doge / 临时 AI 角色，固定由牛同学承担「提问、疑惑、恍然大悟」。
- 只用 `assets/` 中登记的正式形象（正面抠图：`assets/images/characters/niu-classmate-front-cutout.png`）；表情/动作变体后续统一入库到 `assets/images/characters/`。

## 六、动效节奏

| 场景 | 做法 | 时长 |
|---|---|---|
| 色块入场 | 由下往上 40px 位移 + 淡入，`power3.out` | 0.35–0.5s |
| 逐层搭建 | 组件按讲解顺序一个个出现，间隔 0.15–0.3s | 随口播 |
| 焦点切换 | 当前块描边变 `--accent-glow`，其余降到 40% 不透明 | 0.25s |
| 章节转场 | 整屏淡出 → 章节卡大字 scale 0.92→1 | 0.3s |

- 禁止：旋转飞入、弹跳过度、多元素同时乱动。一个时刻只有一个视觉焦点。
- 背景保持静止或极慢漂移（网格 ≤ 8px/s）。
