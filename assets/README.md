# 通用素材库

用于集中存放多个视频或平台会重复使用的公共素材。单条视频专用素材应放在对应的 `videos/<video-project>/assets/` 中。

- `avatars/`：头像、品牌形象与账号图标
- `images/characters/`：角色设定与角色图
- `images/backgrounds/`：通用背景
- `images/illustrations/`：通用插图
- `images/thumbnails/`：可复用封面图形与缩略图素材
- `audio/music/`：通用音乐
- `audio/sfx/`：通用音效
- `audio/voice/`：可复用语音素材
- `videos/broll/`：通用 B-roll
- `videos/overlays/`：通用视频叠加层
- `videos/characters/`：牛同学等角色动作视频
- `fonts/`：已确认可用授权的字体
- `templates/covers/`：封面模板
- `templates/captions/`：字幕模板
- `templates/projects/`：视频工程模板（`explainer-vertical/`：科普讲解竖屏组件模板）
