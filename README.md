# 牛同学不上班

面向多个内容平台的 AI 短视频生产工作区。账号正式名称为 **牛同学不上班**。

## 目录结构

```text
media/
├─ AGENTS.md             项目规则与 Agent 工作约定
├─ brand/                账号定位、品牌口径、角色与视觉规范
├─ content/
│  ├─ ideas/             选题池与灵感
│  ├─ research/          调研、来源与事实核验
│  └─ scripts/           跨平台母稿、口播稿与分镜草案
├─ assets/               跨视频复用的公共素材
│  ├─ avatars/           头像与账号图标
│  ├─ images/            角色、背景、插图和封面图
│  ├─ audio/             音乐、音效与通用语音
│  ├─ videos/            B-roll 与叠加层等通用片段
│  ├─ fonts/             已确认授权的字体
│  └─ templates/         封面、字幕与工程模板
├─ videos/               一条视频一个独立制作工程
├─ publishing/           发布日历、平台文案、规范与数据复盘
├─ archive/              已停用或已替换内容
└─ .agents/              Agent 辅助配置
```

## 内容流转

`选题 → 调研核验 → 母稿/分镜 → 视频制作 → 多规格导出 → 多平台发布 → 数据复盘 → 归档`

详细约定见 `AGENTS.md`，各视频工程的具体制作要求见其目录内的 `AGENTS.md`。

## Git 提交范围

- 提交项目文档、选题与脚本、研究记录、发布文案，以及视频工程的配置、源码、分镜和复核结论。
- 提交画面和声音直接引用的素材，包括正式角色图、已授权字体、工程内的配音、音效、音乐和源视频。复制到模板工程的素材也需要保留，模板才能独立使用。
- 不提交本地依赖和环境、HyperFrames 运行状态与预览缓存、命令输出、测试音频、渲染成片及检查截图；具体规则见根目录 `.gitignore`。
- 成片保存在各工程的 `renders/` 中并按版本命名；如需通过 Git 分发成片或大型原始素材，应单独制定 Git LFS 规则，不要直接加入普通 Git 历史。
